# Nightreign Everdarks Full Fights
# ====================ENG====================
Adds the 1st phase of the Nightlords' battles to the Everdark Sovereigns' battles.
<pre>Note: Seamless Co-op is already integrated into this mod (meaning the Seamless Co-op save file will be used).

Other Note: Music and visuals in the Nightlord arenas WILL be buggy(for now).</pre>

## Only expeditions with modified Nightlords are available. Right now, this includes:
- **Adel (Gaping Jaw)**: Maximum HP increased by 50%. Phase 2 starts at 66% max HP, Phase 3 starts at 33% max HP.
<pre>(Therefore, only the Adel expedition is currently available).</pre>

## Setup & Installation:

- **Requirements:** You must have Mod Engine 3 (ME3) installed to run the `.me3` file.
- **Mod Folder:** The `mod` folder can be placed anywhere, but it must be in the same directory as the `EverdarksFull.me3` file.
- **How to Launch:** Start the game by running `EverdarksFull.me3`. Once the game is running, you can safely close the `EverdarksFull.me3` window.

# ====================RUS====================

Добавляет 1-ую фазу битвы с Ночными Владыками в битвы с Владыками Вечной тьмы.
<pre>Примечание: Мод уже включает в себя Seamless Co-op (это означает, что будет использоваться его файл сохранения).

Другое примечание: Музыка и визуальные эффекты на аренах Ночных Владык БУДУТ работать с ошибками (пока что).</pre>

## Доступны только те экспедиции, в которых Ночные Владыки были изменены. На данный момент это:
- **Адель (Зияющая Пасть)**: Максимальное здоровье (HP) увеличено на 50%. Вторая фаза начинается при 66% от макс. HP, третья фаза — при 33% от макс. HP.
<pre>(Следовательно, в данный момент доступна только экспедиция с Аделем).</pre>

**Установка и настройка:**

- **Требования:** Для запуска файла `.me3` необходимо установить Mod Engine 3 (ME3).
- **Папка с модом:** Папку `mod` можно разместить где угодно, но она должна находиться в той же папке, что и файл `EverdarksFull.me3`.
- **Как запускать:** Запустите игру, открыв файл `EverdarksFull.me3`. После того, как игра заработает, вы можете спокойно закрыть окно `EverdarksFull.me3`.
